# Student Record Management System in C

A menu-driven Student Record Management System using singly linked lists, dynamic memory allocation, searching, sorting, modification, deletion, reversal, and file handling.

## Files

- header.h
- main.c
- add.c
- delete.c
- show.c
- modify.c
- file.c
- sort.c
- reverse.c
- Makefile

## Compile

```bash
make
```

## Run

```bash
./student
```

## Clean

```bash
make clean
```

## Data File

Records are saved in:

```text
student.dat
```
