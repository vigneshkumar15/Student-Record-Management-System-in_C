# STUDENT RECORD MANAGEMENT SYSTEM

A menu-driven C project using a **Singly Linked List** to manage student records.

### Features

* Add, delete and modify student records
* Display student records
* Sort by name or percentage
* Reverse the linked list
* Save and load records using `student.dat`
* Dynamic memory allocation

### Files

* `header.h`
* `stud_main.c`
* `stud_add.c`
* `stud_del.c`
* `stud_show.c`
* `stud_mod.c`
* `stud_save.c`
* `stud_sort_rev.c`
* `Makefile`

### Compile

```bash
make
```

### Run

```bash
./student
```

### Clean

```bash
make clean
```
